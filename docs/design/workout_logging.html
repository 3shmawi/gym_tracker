Azm · Design System v1 · Oct 2026

Log a set in one tap, between breaths.

Design system and core screens for the workout-logging flow. Dark + Arabic RTL first, English/LTR and light shown for the key screens. Every spec below maps to AppColors, AppTextStyles, AppDimens and widgets in lib/core/ui/app_ui.dart.

The one decision that shapes everything

The active workout is a scrolling list with the current exercise expanded, plus a fixed logging dock in the thumb zone. I rejected one-exercise-per-page swipe (Fitbod style): swipe direction is ambiguous in RTL, it hides what's next, it splits supersets across pages, and an accidental swipe with a sweaty thumb loses your place. Strong and Hevy's full spreadsheet of every set is the other extreme: tiny cells, and the user has to hunt for the next empty row. The hybrid keeps the overview of a list and the focus of a single card. The dock always holds the next unlogged set, so the user never has to find it.

Dark is the reference theme. Glass is a tint over the brand gradient (AppBackground). Critical numbers never sit on raw glass: they go on surfaceSolid or a glass layer with ≥ 62% opacity, which keeps contrast predictable. Every text pair below passes 4.5:1 on its surface.

Trend badges always pair color with an arrow and a word ("زوّد ↑"), so they never rely on color alone.

Type

Inter for every number (tabular figures, FontFeature.tabularFigures()), Cairo for Arabic words. Numbers stay Western digits: weight plates, machines and gym whiteboards in Egypt use them, and Inter's digits are wider and easier to read from 50 cm than Arabic-Indic digits at the same size. Numbers are wrapped in an LTR isolate so "22.5 × 12" never reorders in RTL.

Spacing, radii, glass layers, motion

Spacing (×.w)

4 · 8 · 12 · 16 · 24 · 32. Screen gutter 16. Card padding 14/16. Dock padding 16, bottom 30 + safe area. Add sm2 = 12 to AppDimens.

Radii (×.r)

chip 10 · stepper key 16 · banner 18 · stepper 20 · card 24 · button/pill 30 (full) · dock/sheet 32 top. Add radiusXl = 24, radiusFull = 999.

Touch targets

Logging controls 56 (± keys, log button 60 high). Everything else 48 (icon buttons, chips row height 48 hit area). Add targetLog = 56, ctaHeight = 60.

Glass layers

L0 brand gradient · L1 cards (GlassQuality.minimal in lists) · L2 dock, timer pill, sheets (standard). Never more than 2 stacked. Lite: solidSurface + 1 px edge, no shadow.

Motion

Tap feedback 120 ms · state change 200 ms easeOutCubic · expand/collapse card 260 ms Curves.easeInOutCubicEmphasized · sheet 300 ms spring (damping 0.86) · timer pill in 220 ms slide-up + fade. Reduce motion: crossfade 150 ms, no slide, no scale.

Haptics

± step: selectionClick · Log set: lightImpact · Exercise complete: mediumImpact · Rest over: notification success (heavy ×2 + sound if in background) · Finish: success · Delete: warning.
